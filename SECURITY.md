# Security Policy

## Supported Versions

Security fixes are applied to the latest release only.

| Version | Supported |
| ------- | --------- |
| 1.5.x   | Yes       |
| < 1.5   | No        |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Send an e-mail to David Carton at [david@notrac.be](mailto:david@notrac.be) with:

- A description of the vulnerability and its impact.
- Steps to reproduce, or a proof of concept.
- The affected version and environment.

You can expect an acknowledgement within 5 business days. Confirmed vulnerabilities will be fixed as soon as possible, and you will be credited in the release notes unless you prefer to remain anonymous.
